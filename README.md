# مطبخي

مطبخي تطبيق ويب تقدمي (PWA) لاكتشاف الوصفات والطهي بالمكونات المتاحة، بواجهة عربية متجاوبة للهاتف والكمبيوتر.

## تشغيل محلي
افتح المشروع عبر خادم محلي مثل VS Code Live Server. يلزم HTTPS أو localhost لتجربة Service Worker وبعض واجهات المتصفح.

## نشر GitHub Pages
من إعدادات المستودع: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

## المحتوى
- وصفات أساسية ووصفات عالمية وأطباق حارة.
- 52 وصفة حلوى بالمعرّفات 25–76، مع مقادير وشرح مكونات وخطوات وأوقات تحضير وطهي وراحة وإجمالي وحصص وصعوبة.
- صور الأطباق والمكونات للحلويات عبر بحث مطابق في Wikimedia Commons عند توفر نتيجة؛ يعرض التطبيق مصدر الصورة وترخيصها، ولا يضع صورة بديلة عشوائية عند عدم العثور على تطابق.
- تصنيفات حسب نوع الطبق والمطبخ والبحث بالمكونات.

## أدوات مطبخي
- اقتراح وصفات من المكونات التي تدخلها.
- مساعد صورة للمكونات: معاينة الصورة وإدخال أسماء المكونات يدوياً. **التعرف الآلي الفعلي على الصور يحتاج ربط نموذج رؤية/خدمة AI، ولم تتم إضافة مفتاح API أو خادم لهذا الغرض.**
- بدائل عملية للمكونات.
- تقديرات غذائية أولية فقط للمكونات التي يمكن مطابقة اسمها ووزنها؛ ليست بيانات تغذية دقيقة أو طبية.
- تسجيل تكلفة الوصفة بالدينار التونسي وحساب تكلفة الحصة.
- حاسبة تحويل مقادير الحلويات حسب مساحة القالب.
- محول وحدات ودرجات حرارة، وبحث صوتي إذا كان المتصفح يدعمه.
- دفتر وصفات خاص بالجهاز، تحدي مطبخي، مشاركة الوصفة، وطباعة المفضلة إلى PDF.
- تصدير واستعادة نسخة احتياطية من بيانات المستخدم المحلية.
- حفظ بيانات الوصفة وطلب تخزين صورها المتاحة للعمل دون اتصال.

## الخصوصية وحدود المزامنة
المفضلة والمشتريات والمكونات والخطة والتقييمات والأسعار والوصفات الخاصة تُحفظ محلياً في المتصفح. لا توجد مزامنة بين أجهزة مختلفة أو حسابات مستخدمين أو مجتمع عام في هذه النسخة؛ ذلك يتطلب خدمة خلفية وقاعدة بيانات وصلاحيات آمنة. الصور الخارجية تحتاج اتصالاً أول مرة حتى تُخزّن مؤقتاً، وقد لا تتوفر كل الصور دون اتصال.

## PWA والتحديث
ملف `service-worker.js` يخزّن ملفات التطبيق الأساسية ويخزّن الصور التي يطلبها المستخدم، مع إصدار cache متجدد. قد يحتاج المتصفح إلى تحديث الصفحة بعد تثبيت نسخة جديدة.

## التحقق
فُحصت صياغة JavaScript للملفات الأساسية، واكتمال حقول وصفات الحلويات الـ52، واتساق أوقات كل وصفة، ودمج قاعدة الوصفات مع إزالة المعرّفات المكررة. لم يُجرَ اختبار بصري آلي شامل على أجهزة فعلية.
