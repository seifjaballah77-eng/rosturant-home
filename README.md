# مطبخي

تطبيق ويب تقدمي للوصفات والطهي، بواجهة عربية وهوية بنفسجية/سوداء.

## تشغيل محلي
افتح المشروع عبر خادم محلي (مثل VS Code Live Server). بعض ميزات PWA والإشعارات تحتاج HTTPS أو localhost.

## النشر على GitHub Pages
من إعدادات المستودع: **Settings → Pages → Deploy from a branch → main → /(root) → Save**. بعد اكتمال النشر سيظهر رابط الموقع.

## ما تتضمنه النسخة الأولية
- واجهة متجاوبة للهاتف والكمبيوتر.
- بحث في وصفات تجريبية وإدخال المكونات المتوفرة.
- تفاصيل وصفات وخطوات ومؤقت بسيط.
- قائمة مشتريات ومفضلة محفوظتان محلياً.
- وضع ليلي/نهاري.
- manifest وservice worker للتثبيت والتخزين المؤقت وتحديث ملفات التطبيق.
- طلب إذن إشعارات المتصفح؛ تنبيهات المؤقت تعمل أثناء بقاء الصفحة مفتوحة.

## ملاحظات مهمة
هذه نسخة تأسيسية وليست موسوعة عالمية مكتملة. الصور خارجية وتحتاج اتصالاً أول مرة؛ لم تُضمّن قاعدة بيانات وصفات ضخمة أو ترجمة فيديوهات أو إشعارات خلفية مضمونة. تحديث Service Worker يُحمّل تلقائياً ويُفعّل وفق دورة المتصفح، وقد يلزم تحديث الصفحة لتشغيل النسخة الجديدة. الإشعارات عند إغلاق التطبيق تتطلب بنية Push server واشتراكاً وإعدادات إضافية غير مضافة هنا.
